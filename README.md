# cy-data-test

This is a sample project I developed in Cypress

## Pre-requirements

It is required to have Node.js and npm installed to run this project.

> I used versions `v22.12.0` and `10.9.0` of Node.js and npm, respectively. I suggest you use the same or later versions.

## Installation

Run `npm install` (or `npm i` for the short version) to install the dev dependencies.

## Tests
Normal
npm rum cy:open  


Com interface de celular 
npm rum cy:open:mobile

Rodar em integração continua com interface de celular .
npm run test:mobile
